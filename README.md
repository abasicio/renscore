# RenScore

Fodbold- og UFC-resultater uden reklamer, notifikationer eller konto, med et design inspireret af SofaScore.

**Åbn:** https://abasicio.github.io/renscore/

På iPhone: åbn linket i Safari → **Del** → **Føj til hjemmeskærm**. Så åbner den som en almindelig app.

- Kampe pr. dag i de ligaer du vælger (Superligaen, CL/EL/ECL, Premier League, La Liga, Bundesliga, Serie A, Ligue 1, Süper Lig m.fl. + 2. divisioner og pokaler)
- Kampside med kampforløb, statistik, opstilling på bane og stilling
- Favoritter med form, næste og seneste kamp
- UFC-stævner

Data hentes direkte fra ESPN's åbne API i browseren. Valg og favoritter gemmes kun lokalt på telefonen.
Ren HTML/CSS/JavaScript uden byggetrin.
